# Engdoc.ai চালু করার নিয়ম (সম্পূর্ণ ফ্রি)

© English Doctor

Engdoc.ai একটি ইনস্টলযোগ্য ওয়েব অ্যাপ (PWA)। Android, iPhone, ট্যাবলেট ও কম্পিউটার, সব ডিভাইসে এটা অ্যাপের মতো ইনস্টল করা যায়। কোনো প্লে-স্টোর লাগে না।

## অ্যাপে যা আছে
- **৪টি লেভেল, ২৪টি ইউনিট:** Foundation → Elementary → Intermediate → Advanced
- **প্রতিটি ইউনিটে:** ৫টি বাক্য (ইংরেজি ও বাংলা), শুনে বলার উচ্চারণ স্কোর, বলার কাজ, আর Doctor Buddy-র সাথে AI রোল-প্লে
- **AI সংশোধন:** প্রতিটি ভুল বাংলায় বুঝিয়ে দেয়, আর তা "ভুলের খাতা"-য় জমা হয়
- **IELTS Speaking:** Part 1 (১০টি টপিক), Part 2 (৮টি কিউ কার্ড, ১ মিনিট প্রস্তুতি ও ২ মিনিট বলার টাইমার), Part 3, এবং আনুমানিক ব্যান্ড ফিডব্যাক
- **Say it in English:** বাংলায় লিখলে বা বললে ইংরেজি কীভাবে বলতে হয় দেখায়
- **অগ্রগতি:** streak, সম্পন্ন ইউনিট আর নোটবুক শিক্ষার্থীর নিজের ফোনেই সেভ থাকে। লগইন লাগে না।

## ধাপ ১: Gemini API Key নাও (ফ্রি)
1. https://aistudio.google.com এ নিজের Google অ্যাকাউন্ট দিয়ে ঢোকো।
2. **Get API key** → **Create API key** চাপো।
3. Key-টা কপি করে নিরাপদ জায়গায় রাখো। **কাউকে দেবে না, কোথাও পোস্ট করবে না।**

## ধাপ ২: GitHub-এ ফাইলগুলো আপলোড করো
1. https://github.com এ ফ্রি অ্যাকাউন্ট খোলো।
2. **New repository** চাপো। নাম দাও `engdoc-ai`, তারপর **Create repository**।
3. **uploading an existing file** লিংকে চাপো।
4. zip ফাইলটা আনজিপ করো। ভেতরের **সব ফাইল আর ফোল্ডার** (`api`, `icons` সহ) টেনে এনে ছেড়ে দাও।
5. নিচে **Commit changes** চাপো।

## ধাপ ৩: Vercel-এ ফ্রি হোস্টিং
1. https://vercel.com এ **Continue with GitHub** দিয়ে সাইন আপ করো (Hobby প্ল্যান ফ্রি)।
2. **Add New → Project** → `engdoc-ai` রিপোজিটরির পাশে **Import** চাপো।
3. **Environment Variables** অংশে লেখো:
   - Name: `GEMINI_API_KEY`
   - Value: ধাপ ১-এর key
4. **Deploy** চাপো। ১–২ মিনিট পর `engdoc-ai.vercel.app` এর মতো একটা লিংক পাবে। এটাই তোমার অ্যাপ।

> `engdoc.ai` নামের নিজস্ব ডোমেইন চাইলে আলাদা করে কিনতে হবে (.ai ডোমেইনের খরচ আছে)। তারপর Vercel → Settings → Domains-এ যোগ করা যায়। ফ্রি থাকতে চাইলে vercel.app লিংকই যথেষ্ট।

## ধাপ ৪: শিক্ষার্থীরা কীভাবে ইনস্টল করবে
- **Android (Chrome):** লিংক খোলো → উপরে **⬇ Install** বাটন, অথবা ⋮ মেনু → **Install app / Add to Home screen**
- **iPhone (Safari):** লিংক খোলো → Share ⬆ → **Add to Home Screen**
- **কম্পিউটার (Chrome/Edge):** অ্যাড্রেস বারের ডানে ইনস্টল আইকন

## দরকারি তথ্য
- **দৈনিক সীমা:** ফ্রি কোটা বাঁচাতে প্রতিটি ডিভাইসে দিনে ৪০টি AI উত্তর রাখা আছে। বদলাতে চাইলে `app.js` ফাইলের শুরুতে `DAILY_LIMIT` সংখ্যাটা বদলাও। বাক্য অনুশীলনের উচ্চারণ স্কোরে কোনো AI খরচ হয় না, এটা সীমাহীন।
- **ফ্রি কোটা:** Gemini-র ফ্রি সীমা পুরো প্রজেক্টের জন্য একটাই। অনেক শিক্ষার্থী একসাথে ব্যবহার করলে দিনের কোটা শেষ হতে পারে। তখন অ্যাপ বিনয়ের সাথে "কাল আবার এসো" দেখাবে। বেশি দরকার হলে AI Studio-তে billing চালু করা যায়।
- **গোপনীয়তা:** ফ্রি টিয়ারে Google পাঠানো ডেটা নিজেদের পণ্য উন্নয়নে ব্যবহার করতে পারে। তাই অ্যাপে শিক্ষার্থীদের ব্যক্তিগত তথ্য না লিখতে বলা আছে।
- **মাইক্রোফোন:** কথা বলে উত্তর দেওয়া Chrome, Edge আর Safari-তে চলে। Firefox-এ টাইপ করে চালানো যায়। বাংলায় বলা (bn-BD) সব ব্রাউজারে নাও চলতে পারে।
- **কনটেন্ট বদলানো:** লেভেল, ইউনিট, বাক্য, IELTS টপিক আর দৈনিক টপিক সব `content.js` ফাইলে আছে। নতুন ইউনিট যোগ করতে একই ধাঁচে লিখলেই হবে। GitHub-এ ফাইল এডিট করলে Vercel নিজে থেকে আপডেট করে দেবে।
- **মডেল বদলানো (ঐচ্ছিক):** Vercel-এ `GEMINI_MODEL` নামে আরেকটা Environment Variable দিয়ে নির্দিষ্ট মডেলের নাম দেওয়া যায়। না দিলে সর্বশেষ Flash মডেল ব্যবহার হবে।
